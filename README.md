# Portfolio

Site personnel de Moundher Mghezzi-Larafi, développeur web en recherche d'alternance en Île-de-France.

Réalisé en HTML, CSS et JavaScript, sans framework. L'animation d'accueil est une simulation de tissu masse-ressort (intégration de Verlet) dessinée sur un `<canvas>`, que l'on peut tirer avec la souris ou le doigt.
